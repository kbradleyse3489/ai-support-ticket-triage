# Release notes

Version 1.0, October 18, 2026.

This release includes the runnable local Streamlit app, saved selected model, complete Python source, pinned dependencies, licensed and attributed public dataset, reproducible train/validation/test evaluation, seven-cell executed notebook, evaluation figures, diagnostic fixtures, 26 passing tests, and editable case study.

The project is a banking-support intent benchmark and assistive workflow demonstration. It has not been validated on real employer IT tickets or deployed to production. No handling-time improvement, autonomous routing, account action or financial decision is claimed. Read the README, model card and failure-analysis files before interpreting the scores.

The source code and model can run offline after dependency installation. Joblib files must be trusted before loading. All inputs used for the included demonstration and tests are public benchmark text or clearly marked synthetic scenarios.

The MANIFEST.sha256 file records the exact packaged files. Re-running training or rebuilding documents changes those hashes; rerun scripts/package_project.py to create a new release manifest and archive.
